# ISDA NANAMAN

This repository is only made because the developer is practicing Tailwindcss. Isda nanaman is from the Filipino word "Isda" means fish and "Nanaman" means again, which known by putting fish again and again with the same type of delicacies or dishes. This website aims to eliminate the problem of having a fish again as delicay as it provides a lot of fish dish that can try by local peoples near water bodies.
